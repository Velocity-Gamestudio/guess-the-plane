# ✈️ Guess the Plane

**Guess the Plane** is an interactive aviation game where players identify different aircraft from visual clues, test their aviation knowledge, and compete for the highest score.

## 🎮 How to Play

1. Start a round.
2. Look at the aircraft and available clues.
3. Choose the plane you think is correct.
4. Earn points for correct answers.
5. Try to beat your highest score!

## ✈️ Features

- Identify different aircraft
- Test your aviation knowledge
- Score-based gameplay
- Simple and engaging interface
- Fun for aviation fans of all experience levels
